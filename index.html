Matriz de Preferência

Estruture uma decisão em cinco passos: critérios, alternativas, scores, pesos e tomada de decisão.

Problema

Definição do problema

Descreva a decisão que será analisada ao longo do processo.

Como fazer este passo

Defina o título e o contexto do problema. Eles ficam visíveis em todas as etapas, ajudando a manter o foco. Um bom título é objetivo e reflete a escolha que precisa ser feita.

Passo 1

Escolha dos critérios

Os fatores usados para comparar as alternativas.

Como fazer este passo

Liste os critérios que importam para o decisor, como custo, qualidade ou prazo. Eles devem ser qualitativos e diferenciar as alternativas: um critério em que todas têm o mesmo desempenho não ajuda a decidir. Use o mínimo necessário; são pelo menos 2.

Dica: cole uma lista com um nome por linha para adicionar vários de uma vez.

Nenhum critério adicionado ainda

Passo 2

Definição das alternativas

As opções entre as quais o decisor vai escolher.

Como fazer este passo

As alternativas são as opções disponíveis, como fornecedores, locais ou projetos. Pense em todas as possibilidades que atendem ao problema: a análise fica mais rica com mais alternativas (de 4 a 7 é uma boa referência). São pelo menos 2.

Dica: cole uma lista com um nome por linha para adicionar vários de uma vez.

Nenhuma alternativa adicionada ainda

Passo 3

Atribuição de scores

O desempenho de cada alternativa em cada critério, de 0 a 10.

Como fazer este passo
  1. Escolha a melhor alternativa no critério e defina seu score (âncora superior).
  2. Escolha a pior e defina seu score (âncora inferior).
  3. Posicione as demais comparando com as âncoras.

Uma alternativa pior em todos os critérios pode ser eliminada.

Passo 4

Atribuição de pesos

A relevância relativa de cada critério na decisão.

Como fazer este passo

Os pesos refletem a relevância de cada critério. Eles vêm depois dos scores porque o intervalo de desempenho de cada critério influencia sua relevância. Escolha o método para ver as instruções.

Passo 5

Tomada de Decisão

Ranking das alternativas e análise completa da Matriz de Preferência.

Como ler o resultado

O resultado é a soma ponderada dos scores. A alternativa com maior pontuação é a indicada, mas faça uma análise crítica: veja se o resultado faz sentido no contexto e observe os critérios em que a vencedora teve pior desempenho antes de decidir.

Configurações

Sugestões de critérios por IA (opcional)

Com uma chave do Google Gemini, a ferramenta sugere critérios a partir do título e do contexto do problema.

Nenhuma chave configurada. As sugestões de critérios por IA estão desligadas.

A chave fica salva só neste navegador. Para obter uma, acesse o Google AI Studio. Em computadores compartilhados, use "Limpar" ao terminar.

As sugestões são limitadas aos critérios, para que scores e pesos continuem sendo julgamento humano.
